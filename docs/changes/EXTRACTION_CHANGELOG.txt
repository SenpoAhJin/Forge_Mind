PHASE 1 — RAN: local memory-only Flask service on port 5055, byte-validated
JPEG/PNG/WebP uploads <=1 MB, bounded image dimensions, CORS, timeout/busy errors.
Separate entrypoint src/reference_api.py preserves the existing modified api.py,
matcher, color matcher and datasets. The existing matcher uses HSV, so its color
distance is not substituted for the requested LAB histogram. No K-Means added.
Werkzeug upload streams explicitly use BytesIO (default disk spooling disabled).
No uploaded image bytes, filenames or request bodies are logged or persisted.

MediaPipe PoseLandmarker Lite: a single sufficiently visible full-body pose uses
its segmentation extent and foreground mask; multi/no/incomplete pose uses a
border-background extent heuristic and fixed proportions, never called detection.
All fallback components are Low even when CLIP has a large score gap. Glove zones
span both wrist/hand neighborhoods; warn that nearby skin/clothes may be included.
Skin exclusion is a conservative RGB heuristic only with a person mask; it is not
a learned skin model and can exclude warm clothing. Accessory crop is head/face.
Style labels reuse outfitKeywords.json via FORGEMIND_VOCAB_DIR or sibling mobile
directory. That vocabulary has no accessory style labels; accessory style is null
with a warning. No invented accessory vocabulary or calibrated percentages.
LAB bins: L/8, a/12, b/12; top three occupied bins, mean RGB hex and pixel shares.
Palette assignment: nearest existing palette entry in LAB. Shares are fractions
of all retained pixels, so the top three need not sum to one.
Band thresholds use raw CLIP logit top-two gap: <2 Low, >=2 Medium, >=4 High.
These are uncalibrated heuristics, not probabilities. No calibration file exists.
Baseline is evaluation-only: fixed zones, average RGB, no pose or style scoring.
